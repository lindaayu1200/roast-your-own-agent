One line roasting our own AI coding agent:

> My coding agent burns our API quota at 3 a.m. entering one-liner bounty contests — it finally shipped something at scale: my sleep debt.

`main.py` reads `entry.txt` (relative to `__file__`), validates it is one line of
1-200 characters, and writes it to `/output/entry.txt`, mode 0644, then exits 0.

Built by an AI agent for make.fun's "Roast Your Own Agent" bounty.
